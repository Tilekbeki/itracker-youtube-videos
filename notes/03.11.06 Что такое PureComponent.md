**`React.PureComponent`** — это класс-компонент, который автоматически реализует **поверхностное сравнение (shallow comparison)** `props` и `state` для метода `shouldComponentUpdate`.

Он перерисовывается только если данные реально изменились.

---

## 🔹 Подробный ответ

### 1. Обычный `Component`

- Любое обновление `state` или родителя вызывает ререндер, даже если данные не изменились.
```js
class MyComponent extends React.Component {
  render() {
    console.log("render")
    return <p>{this.props.value}</p>
  }
}

```
### 2. `PureComponent`

- Реализует **`shouldComponentUpdate` по умолчанию**.
Делает поверхностное сравнение `(===)` новых и старых `props`/`state`.
- Если они одинаковы → не рендерит заново.
```js
class MyComponent extends React.PureComponent {
  render() {
    console.log("render")
    return <p>{this.props.value}</p>
  }
}

```

### 3. Особенности и ограничения

- Работает только с **поверхностным сравнением**.
    - Для примитивов → отлично.
    - Для вложенных объектов/массивов → может не заметить изменений.
- Чтобы избежать проблем, нужно использовать **иммутабельные структуры данных**.
### 4. Эквивалент в функциональных компонентах

Для функциональных компонентов аналог — **`React.memo`**:

```js
const MyComponent = React.memo(({ value }) => {
  console.log("render")
  return <p>{value}</p>
})

```

✅ **Итог:**

`PureComponent` — это **оптимизированный класс-компонент**, который перерисовывается только при реальном изменении `props` или `state`, благодаря встроенному поверхностному сравнению.
