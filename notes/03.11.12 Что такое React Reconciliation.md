**React Reconciliation** — это процесс сравнения старого и нового Virtual DOM для определения минимальных изменений, которые нужно внести в реальный DOM. Используется алгоритм **diffing** (сравнение), чтобы обновлять только изменившиеся узлы.

---

## 🔹 Подробный ответ

- **Зачем нужен:**
    
    Реальный DOM обновлять дорого. React работает с Virtual DOM и при изменениях не перерисовывает всё дерево, а только то, что реально изменилось.
    
- **Как работает Reconciliation:**
    
    1. React создаёт **новый Virtual DOM** при каждом изменении состояния или пропсов.
    2. Сравнивает его со старым Virtual DOM (**diffing algorithm**).
    3. Находит минимальный набор изменений.
    4. Обновляет только изменённые части реального DOM (**patching**).
- **Ключевые оптимизации:**
    
    - Если элементы разного типа (например `<div>` → `<span>`), React полностью пересоздаёт этот узел.
    - Если тип одинаковый, но изменились `props` или `children` → обновляет только их.
    - Атрибут **`key`** помогает эффективно отслеживать элементы списка при добавлении/удалении/перестановке.
- **Влияние:**
    
    Благодаря Reconciliation React остаётся быстрым и отзывчивым, даже при большом количестве рендеров.
