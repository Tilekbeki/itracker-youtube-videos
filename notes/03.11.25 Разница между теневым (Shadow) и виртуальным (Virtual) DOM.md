- **Virtual DOM** — это абстракция (виртуальное представление DOM в памяти), которую использует React для оптимизации обновлений UI.
- **Shadow DOM** — это технология браузеров (часть Web Components), позволяющая создавать изолированные DOM-деревья с собственными стилями.

---

### 1. Virtual DOM

- Это **виртуальная копия DOM**, которая существует в памяти.
- React использует Virtual DOM, чтобы сравнивать (diffing) старое и новое состояние интерфейса и обновлять только изменившиеся элементы.
- **Плюсы:** оптимизация производительности, декларативный подход.
- **Минусы:** это абстракция, она не даёт изоляции стилей или структуры.

Пример:

→ Virtual DOM → сравнивает с предыдущим состоянием → минимально обновляет реальный DOM.

---

### 2. Shadow DOM

- Это **фича браузеров** (Web Components API).
- Позволяет создавать **изолированные компоненты** с собственным DOM и стилями, которые не конфликтуют с остальной страницей.
- Используется в **кастомных элементах (custom elements)**, например в `<video>`, `<input type="range">`.
- Структура Shadow DOM скрыта от основного документа.
### 📌 Сравнительная таблица

|                  | **Virtual DOM** (React)             | **Shadow DOM** (Web Components)<br>      |
| ---------------- | ----------------------------------- | ---------------------------------------- |
| Где используется | React, Vue и др. фреймворки         | Нативно в браузерах (Web Components API) |
| Что это          | Виртуальная копия DOM в памяти      | Изолированное DOM-дерево внутри элемента |
| Цель             | Оптимизация обновлений UI           | Инкапсуляция структуры и стилей          |
| Изоляция         | ❌ Нет                               | ✅ Да                                     |
| Доступность      | Управляется библиотекой/фреймворком | Поддерживается браузером нативно         |
