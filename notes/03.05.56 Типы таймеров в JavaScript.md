- **setTimeout**
- **setInterval**

Список активных таймеров общий и для одноразовых таймеров, установленных с помощью [`setTimeout()`](https://doka.guide/js/settimeout/) и для регулярных таймеров, установленных с помощью `setInterval()`. Потому в `clearInterval()` можно использовать идентификаторы обоих типов таймеров.

Однако для одноразовых таймеров лучше использовать отдельную функцию [`clearTimeout()`](https://doka.guide/js/cleartimeout/) для лучшей читаемости.
