`shouldComponentUpdate(nextProps, nextState)` — метод классового компонента, который определяет, нужно ли заново рендерить компонент. Возвращает `true` (перерендер) или `false` (пропустить обновление). Используется для оптимизации производительности.

---

## 🔹 Подробный ответ

- **Когда вызывается:** при изменении `props` или `state` перед методом `render()`.
- **Зачем нужен:** чтобы предотвратить лишние рендеры, если данные не изменились или изменения не влияют на UI.
- **По умолчанию:** возвращает `true` → то есть React всегда будет перерендеривать.
- **Пример:**
```js
shouldComponentUpdate(nextProps, nextState) {
  return nextProps.value !== this.props.value;
}
```
Здесь компонент обновится только если изменился `value`.

- **Альтернативы:**
    - `React.PureComponent` — автоматически сравнивает `props` и `state` поверхностно.
    - В функциональных компонентах — `React.memo` для мемоизации.
