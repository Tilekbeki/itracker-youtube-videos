- **React.memo** — мемоизация компонентов (PureComponent для классовых компонентов)
- **useMemo / useCallback** — мемоизация вычислений и функций.
- **Разделение кода (Code Splitting / React.lazy + Suspense)**. загружаемые по мере необходимости
- **Виртуализация списков** (react-window / react-virtualized). Для длинных списков рендерятся только видимые элементы
- **Ключи (`key`) в списках** — для минимизации DOM-операций.
- **Избегать лишних ререндеров** — правильное управление state и props.

### Управление состоянием
- Разделение state на локальные куски.
- Избегать лишних объектов/массивов при каждом рендере.
- Использование локального state вместо глобального, если это возможно.

### Lazy-loading изображений и компонентов

- Изображения: `<img loading="lazy" />`
- Компоненты: `React.lazy()`
