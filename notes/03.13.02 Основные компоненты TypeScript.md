Основные компоненты TypeScript:

1. **Язык** (типизация + синтаксис).
2. **Компилятор (tsc)** → преобразует TS в JS.
3. **Конфигурация (`tsconfig.json`)** → управляет сборкой.
4. **Инструменты/IDE-поддержка** (IntelliSense, автокомплит).

---

### 1. Язык (Language)

- Расширяет JavaScript **системой типов**:
    - простые типы (`string`, `number`, `boolean`);
    - сложные (`union`, `tuple`, `enum`, `interface`, `type`);
    - продвинутые (`generics`, `utility types`).
- Включает ООП-фичи (классы, модификаторы `public`, `private`, `protected`, `readonly`).

---

### 2. Компилятор (`tsc`)

- Переводит `.ts` → `.js`.
- Проверяет типы (type checking).
- Может таргетировать разные версии JS (`ES5`, `ES6`, `ESNext`).

---

### 3. Конфигурация (`tsconfig.json`)

- Определяет правила компиляции.
    
    Пример:

```json
{
  "compilerOptions": {
    "target": "ES6",
    "module": "commonjs",
    "strict": true,
    "outDir": "./dist"
  }
}
```

### 4. Инструменты и экосистема

- **Поддержка IDE** (VS Code, WebStorm) → автодополнение, навигация по типам.
- **DefinitelyTyped (`@types/`)** → типовые декларации для библиотек JS.
- Интеграция с **Webpack, Babel, ESLint**.
