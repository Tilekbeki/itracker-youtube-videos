- **React** — это библиотека для описания UI (создание компонентов, Virtual DOM, хуки). **React** описывает **как** должен выглядеть интерфейс.
- **ReactDOM** — это пакет, который связывает React с браузерным DOM (рендерит компоненты в `document`). **ReactDOM** отвечает за то, **куда** и **как** этот интерфейс вставить в реальный DOM.
