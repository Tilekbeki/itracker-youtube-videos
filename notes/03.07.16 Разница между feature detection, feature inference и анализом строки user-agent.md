Feature detection — это метод проверки доступности определенных функций в браузере перед их использованием. Это самый надежный способ, поскольку он проверяет непосредственно наличие нужных возможностей, а не полагается на информацию о браузере.

```js
if ("geolocation" in navigator) {
  // Используем геолокацию, так как она поддерживается
  navigator.geolocation.getCurrentPosition(showPosition)
} else {
  // Геолокация не поддерживается
  console.log("Геолокация не поддерживается")
}

```

​

Feature inference — это метод, при котором наличие одной функциональности предполагается на основании существования другой, схожей возможности. Вместо того чтобы проверять нужную функцию напрямую, программа проверяет другую функцию и делает вывод, что раз она есть, значит, и нужная функция тоже должна быть.

```js
if (document.getElementsByTagName) {
  // Предполагаем, что если метод getElementsByTagName существует, // то и другие DOM-функции тоже есть
  document.getElementById("example")
}

```

Анализ строки User-Agent — это метод, при котором проверяется строка

User-Agent

, отправляемая браузером на сервер, чтобы определить тип и версию браузера, операционную систему и другие детали. На основе этих данных делаются предположения о поддерживаемых функциях.
```js
const ua = navigator.userAgent

if (ua.includes("Chrome")) {
  console.log("Это Chrome, делаем что-то для этого браузера")
} else if (ua.includes("Firefox")) {
  console.log("Это Firefox")
}

```
