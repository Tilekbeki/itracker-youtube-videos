**React** — это **библиотека для построения пользовательских интерфейсов**, основанная на компонентах.

- Управляет **View** (в MVC).
- Использует **виртуальный DOM** для эффективного обновления страницы.

---

## 🔹 Подробный ответ

### 1. Основные особенности React

- **Компоненты** — независимые, переиспользуемые блоки UI.
- **JSX** — синтаксис, похожий на HTML, который компилируется в `React.createElement`.
- **Virtual DOM** — обновляет только изменившиеся части интерфейса.
- **Однонаправленный поток данных (props)** — данные идут сверху вниз.
- **Состояние (state)** — управляет динамикой компонентов.
### 2. Пример простого компонента

```js
import React, { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0)
  
  return (
    <div>
      <p>Счётчик: {count}</p>
      <button onClick={() => setCount(count+1)}>Увеличить</button>
    </div>
  )
}
export default Counter

```
- `useState` — хук состояния.
- `onClick` — обработчик события.
- React рендерит UI при изменении состояния, минимально обновляя DOM.

---

### 3. Зачем использовать React

- Быстро строить **интерактивный UI**.
- Переиспользовать компоненты.
- Упрощает поддержку крупных проектов благодаря **структуре компонентов и однонаправленному потоку данных**.

---

✅ **Итог:**

React — это **компонентная библиотека для создания динамических интерфейсов**, которая делает обновление UI эффективным и упрощает управление состоянием.
