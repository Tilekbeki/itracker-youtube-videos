## 🔹 Краткий ответ (для собеса):

- **Union (`|`)** — значение может принадлежать **одному из нескольких типов**.
- **Intersection (`&`)** — значение должно удовлетворять **всем типам сразу**.

---

## 🔹 Подробный ответ

### 1. Union (Объединение `|`)

Используется, когда переменная может быть **или одного, или другого типа**.

```tsx
let id: string | number;

id = "abc"; // ✅
id = 123;   // ✅
id = true;  // ❌

```

👉 Удобно для случаев, когда возможны **несколько вариантов входных данных**.

---

### 2. Intersection (Пересечение `&`)

Создаёт **новый тип**, который включает все свойства/ограничения одновременно.

```tsx
type Person = { name: string };
type Employee = { company: string };

type Worker = Person & Employee;

const dev: Worker = {
  name: "Ulyana",
  company: "OpenAI"
}; // ✅

```

👉 Используется, когда объект должен соответствовать **нескольким типам сразу**.

---

### 3. Сравнение

| Особенность  | Union (`   | `)      | Intersection (`&`)          |
| ------------ | ---------- | ------- | --------------------------- |
| Логика       | "ИЛИ"      | "И"     |                             |
| Пример типов | `string \\ | number` | `{a: string} & {b: number}` |

| Когда применять | Альтернативные варианты | Объединение свойств разных типов |

---

✅ **Итог:**

- **`|` (union)** — это выбор: тип может быть **одним из перечисленных**.
- **`&` (intersection)** — это объединение: значение должно быть **всеми типами сразу**.
