# Redux Toolkit

### `Redux Toolkit`

**Redux Toolkit (RTK)** — официальная библиотека для упрощённой работы с Redux.

### 🔑 Преимущества Redux Toolkit

- Меньше шаблонного кода
- Предсказуемость и безопасность (immutability handled через Immer)
- Встроенные DevTools
- Простая интеграция асинхронных операций

**Redux Toolkit** предоставляет:

1. `configureStore()` — лёгкое создание store с middleware и DevTools.
2. `createSlice()` — автоматическое создание редьюсера и actions.
3. `createAsyncThunk()` — простой способ писать асинхронные действия.
4. `createEntityAdapter()` — удобная работа с коллекциями объектов.
5. Иммутабельность через **Immer** встроенно.
6. Минимизирует boilerplate и улучшает структуру Redux-приложений.

### Основные возможности и функции Redux Toolkit (`configureStore()`,`createSlice()`,`createAsyncThunk()`, `createEntityAdapter()`)

### `React Query`

**React Query** — это инструмент для **фетчинга, кэширования и синхронизации серверных данных** в React.

### 🔹 Основные преимущества React Query

- Автоматический **кэшинг и рефетч данных**.
- Поддержка **background updates**.
- Управление состоянием загрузки (`isLoading`, `isFetching`, `error`).
- Лёгкая интеграция с REST и GraphQL.
- Минимизирует ручное управление локальным state для серверных данных.

**Основные хуки React Query:**

1. `useQuery` — для получения данных.
2. `useMutation` — для изменения данных (POST, PUT, DELETE).
3. `useQueryClient` — доступ к Query Client для управления кэшем.

### Основные хуки

### 1. **useQuery**

- Используется для **получения данных с сервера**.
- Автоматически кэширует, рефетчит, поддерживает loading/error состояния.

---

### 2. **useMutation**

- Используется для **изменения данных** на сервере.
- Может автоматически обновлять кэш (`invalidateQueries`) после мутации.

---

### 3. **useQueryClient**

- Дает доступ к **Query Client** для управления кэшем:
    - `invalidateQueries` — обновление данных
    - `setQueryData` — обновление кэша вручную

### `RTK Query`

**RTK Query** — это **пакет в Redux Toolkit**, упрощающий работу с серверными данными.

- Основные возможности: fetch, кэширование, автоматическое обновление, оптимистичные обновления.
- Основные API:

1. `createApi()` — создаём API с endpoint’ами.
2. `useQuery` и `useMutation` — хуки для компонентов.
3. `providesTags` / `invalidatesTags` — автоматическое управление кэшем.

### 🔹 Преимущества RTK Query

- Встроенное управление кэшем и кэш-инвалидация.
- Автоматическое создание хуков для компонентов.
- Интеграция с Redux — нет отдельного состояния для серверных данных.
- Минимизирует boilerplate кода для фетчинга и мутаций.

### Основные API

### 1. **createApi()**

- Создаём "API slice" с endpoint’ами.

---

### 2. **useQuery**

- Хук для **получения данных**.

---

### 3. **useMutation**

- Хук для **изменения данных**.

---

### 4. **Тэги и кэш**

- `providesTags` — отмечает, какие данные хранит кэш.
- `invalidatesTags` — автоматически обновляет кэш после мутации.
