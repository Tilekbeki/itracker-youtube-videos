`declare` в TypeScript используют, чтобы **объявить переменные, функции, классы или модули, которые существуют, но их реализации нет в коде**.

Обычно это нужно при работе с **внешними библиотеками или глобальными объектами**.

---

## 🔹 Подробный ответ

### 1. Для чего нужно `declare`

- Сообщает компилятору TypeScript: _“эта сущность существует где-то во внешнем коде (JS, библиотека, глобальная переменная), не проверяй её реализацию”_.
- Используется в **ambient declarations** (`.d.ts` файлы).
- Позволяет подключать JS-библиотеки без полной переписи на TS.

---

### 2. Где используется

1. **Глобальные переменные**

```tsx
declare const VERSION: string;

console.log(VERSION); // TS не ругается, хотя определения в коде нет

```

1. **Функции из сторонних скриптов**

```tsx
declare function $(selector: string): any;

$("#app"); // TS считает $ допустимым

```

1. **Модули без типизации**

```tsx
declare module "legacy-lib";

```

1. **Файлы `.d.ts`**

```tsx
// globals.d.ts
declare namespace NodeJS {
  interface ProcessEnv {
    PORT: string;
  }
}

```

---

### 3. Важное отличие

- `declare` ≠ объявление переменной.
- Это только **инструкция для компилятора** → в JS-код оно **не попадает**.

---

✅ **Итог:**

`declare` нужен для того, чтобы **подружить TypeScript с внешними JS-библиотеками, глобальными переменными и API**, не имеющими встроенных типов.
