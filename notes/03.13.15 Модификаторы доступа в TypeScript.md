TypeScript поддерживает модификаторы доступа для классов:

1. **`public`** — доступно везде (по умолчанию).
2. **`private`** — доступно только внутри класса.
3. **`protected`** — доступно внутри класса и его наследников.
4. **`readonly`** — значение нельзя менять после инициализации.

---

---

### 🔹 Комбинации

- Можно сочетать `protected` + `readonly`, `private` + `readonly`.

```tsx
class User {
  protected readonly id: number;
  constructor(id: number) {
    this.id = id;
  }
}

```

---

✅ **Итог:**

Модификаторы доступа позволяют управлять **видимостью и изменяемостью свойств и методов**, повышая инкапсуляцию и безопасность кода.
