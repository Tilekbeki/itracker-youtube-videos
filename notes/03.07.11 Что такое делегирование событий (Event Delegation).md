**Делегирование событий (Event Delegation)** — это техника в JavaScript, которая позволяет обрабатывать события на **родительском элементе**, а не устанавливать обработчики событий на множестве дочерних элементов. Эта техника особенно полезна, когда у нас есть много динамически добавляемых элементов, или когда нужно оптимизировать количество обработчиков событий на странице.

### Как это работает:

События в JavaScript поддерживают механизм **всплытия (bubbling)**, при котором событие, происходящее на одном элементе, передается на его родительские элементы вверх по DOM-дереву. Это позволяет ставить один обработчик на родителя и "ловить" события от дочерних элементов.

### Преимущества делегирования событий:

1. **Меньше обработчиков событий** — нет необходимости добавлять обработчик события для каждого дочернего элемента. Мы можем повесить один обработчик на родитель и обрабатывать все дочерние элементы.
2. **Работа с динамическими элементами** — если элементы добавляются на страницу динамически, обработчики, установленные через делегирование событий, автоматически будут работать с новыми элементами.

**Пример делегирования событий:**

```js
// Есть родительский элемент, внутри которого много дочерних элементов (например, список).
const parent = document.querySelector('.parent');

// Устанавливаем обработчик события на родительский элемент
parent.addEventListener('click', function(event) {
	// Проверяем, был ли клик по нужному элементу
	if (event.target && event.target.matches('li')) {
		console.log('Clicked on a list item:', event.target.textContent);
	}
});
```
