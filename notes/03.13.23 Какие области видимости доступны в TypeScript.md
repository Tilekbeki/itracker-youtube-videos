В TypeScript есть:

1. **Глобальная область видимости** (переменные доступны везде).
2. **Функциональная (function scope)** — переменные внутри функции доступны только в ней.
3. **Блочная (block scope)** — переменные `let` и `const` видны только внутри блока `{}`.
4. **Классовая область видимости** — через `public`, `private`, `protected` (для членов класса).

---

## 🔹 Подробный ответ

### 1. Глобальная область видимости

Объявленные вне функций/классов переменные доступны в любом месте.

```tsx
let globalVar = "Hello";

function foo() {
  console.log(globalVar); // доступ есть
}

```

---

### 2. Функциональная область видимости

`var` имеет область видимости функции.

```tsx
function test() {
  var x = 10;
  console.log(x); // ✅
}
console.log(x); // ❌ Error: x is not defined

```

---

### 3. Блочная область видимости

`let` и `const` доступны только внутри блока `{}`.

```tsx
if (true) {
  let y = 20;
  const z = 30;
  console.log(y, z); // ✅
}
console.log(y, z); // ❌

```

---

### 4. Классовая область видимости (дополнение TS)

TypeScript добавляет модификаторы доступа:

- **public** (по умолчанию) → доступен везде.
- **private** → доступен только внутри класса.
- **protected** → доступен внутри класса и его наследников.

```tsx
class Person {
  public name: string;      // доступно везде
  private age: number;      // только внутри Person
  protected city: string;   // внутри Person и наследников

  constructor(name: string, age: number, city: string) {
    this.name = name;
    this.age = age;
    this.city = city;
  }
}

```

---

✅ **Итог:**

В TypeScript доступны **глобальная, функциональная и блочная области видимости**, как в JS. Дополнительно TypeScript вводит **классовую область видимости** через `public`, `private`, `protected`.
