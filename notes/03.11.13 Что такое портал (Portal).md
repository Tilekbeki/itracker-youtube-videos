**Portal** в React — это способ рендерить дочерние элементы в DOM-узел, находящийся **вне иерархии родительского компонента**. Создаётся с помощью `ReactDOM.createPortal(child, container)`.

---

## 🔹 Подробный ответ:

- **Что это:**
    
    Обычно дочерние компоненты рендерятся внутрь DOM-элемента своего родителя.
    
    **Порталы** позволяют "телепортировать" рендер в другой DOM-узел, который находится за пределами иерархии.
    
- **Пример использования:**
```js
import ReactDOM from "react-dom";

function Modal({ children }) {
  return ReactDOM.createPortal(
    <div className="modal">{children}</div>,
    document.getElementById("modal-root") // отдельный div в index.html
  );
}
```
- **Зачем нужны:**
    1. Для модалок, попапов, тултипов, диалогов (чтобы они не ломали стили родителя).
    2. Для элементов, которые должны визуально отображаться выше всего (например, поверх оверлея).
    3. Для избежания проблем со стилями `overflow`, `z-index`.
- **Особенности:**
    - С точки зрения **React-иерархии**, дочерний элемент остаётся в том же компоненте.
    - С точки зрения **DOM**, он может рендериться где угодно.
    - События работают так, будто элемент остаётся в своём React-дереве (event bubbling сохраняется).
