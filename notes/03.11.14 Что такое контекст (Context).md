Context — это механизм React для передачи данных (например: тема, язык, текущий пользователь) через дерево компонентов без необходимости пробрасывать props на каждом уровне. Создаётся с помощью `React.createContext()`, используется `Provider` и `useContext`.

## 🔹 Подробный ответ:

### 1. **Что это и зачем нужно**

Обычно данные передаются сверху вниз через `props`. Если дерево глубокое, это вызывает проблему **"props drilling"**.

**Context API** решает эту проблему, позволяя объявить данные на верхнем уровне и использовать их в любом компоненте.

---

### 2. **Основные элементы**

- **`React.createContext(defaultValue)`** — создаёт контекст.
- **`Provider`** — оборачивает компоненты и передаёт значение.
- **`useContext`** — хук для получения значения внутри компонента.
### 3. **Пример**
```js
import React, { createContext, useContext } from "react";

// создаём контекст
const ThemeContext = createContext("light");

function App() {
  return (
    <ThemeContext.Provider value="dark">
      <Toolbar />
    </ThemeContext.Provider>
  );
}

function Toolbar() {
  return <ThemedButton />;
}

function ThemedButton() {
  const theme = useContext(ThemeContext); // доступ к контексту
  return <button className={theme}>Моя кнопка</button>;
}


```

### 4. **Когда использовать**

- Тема оформления (light/dark mode)
- Авторизация пользователя (user, roles)
- Локализация (язык интерфейса)
- Глобальные настройки

---

### 5. **Особенности и минусы**

- При изменении контекста **перерисовываются все потребители** → может ударить по производительности.
- Не стоит использовать для всего подряд → чаще применяют для **глобальных данных**.
- Для сложных кейсов лучше **Redux, Zustand, Recoil** и т.п.
