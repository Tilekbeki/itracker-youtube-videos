**Компонент высшего порядка (HOC)** — это функция, которая принимает компонент и возвращает новый компонент с дополнительной логикой или данными.

Это паттерн для **переиспользования кода**.

---

## 🔹 Подробный ответ

### 1. Определение

HOC — это **не компонент, а функция**, которая оборачивает другой компонент.

```js
const EnhancedComponent = withSomething(WrappedComponent);
```

### 2. Пример простого HOC

```js
function withLogger(WrappedComponent) {
  return function (props) {
    console.log("Props:", props)
    return <WrappedComponent {...props} />
  }
}
function Hello({ name }) {
  return <h1>Привет, {name}</h1>
}
const HelloWithLogger = withLogger(Hello) // Использование
;<HelloWithLogger name="Ульяна" />

```
📌 В этом примере HOC добавляет логирование, но может добавлять: данные из API, авторизацию, обработку ошибок и т.д.

---

### 3. Где используют HOC

- Повторное использование логики (например, авторизация).
- Обогащение компонентов данными (например, подключение к Redux через `connect`).
- Обработка UI-паттернов (лоадеры, ошибки).

---

### 4. Особенности

- HOC **не изменяет** переданный компонент, а **создаёт новый**.
- Нужно передавать `props` дальше (`...props`).
- Минус: может возникнуть **"wrapper hell"** (много вложенных HOC).

---

### 5. Альтернатива HOC в современном React

Сейчас чаще используют **хуки (hooks)**, т.к. они позволяют переиспользовать логику без оборачивания компонентов.

---

✅ **Итог:**

HOC — это **функция, оборачивающая компонент**, чтобы добавить к нему новую функциональность. Раньше активно использовались (например, `connect` в Redux), сейчас их часто заменяют хуками.
