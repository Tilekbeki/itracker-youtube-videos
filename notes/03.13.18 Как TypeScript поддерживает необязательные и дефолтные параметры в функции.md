- **Необязательные параметры** обозначаются через `?`.
- **Параметры с дефолтным значением** задаются через =.
- TypeScript проверяет порядок и типы таких параметров при вызове функции.

Примеры:

```tsx
function greet(name?: string) { // необязательный
  console.log(`Hello, ${name || "Guest"}`);
}

function greetDefault(name: string = "Guest") { // дефолтный
  console.log(`Hello, ${name}`);
}

```

---

## 🔹 Подробный ответ

### 1. Необязательные параметры (`?`)

- Параметр может быть **отсутствующим при вызове**.
- Необязательные параметры **должны идти после обязательных**.
- Внутри функции параметр типа `b` имеет тип `number | undefined`.

---

### 2. Параметры с дефолтным значением

- Если аргумент не передан, используется значение по умолчанию.
- Можно сочетать с необязательными параметрами.
- TypeScript **автоматически выводит тип параметра** на основе дефолтного значения, если тип не указан.

---

✅ **Итог:**

TypeScript поддерживает **необязательные параметры** `?` и **параметры с дефолтным значением** =, что позволяет писать более гибкие функции с правильной типизацией и безопасностью.
