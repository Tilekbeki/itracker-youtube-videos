**JSX (JavaScript XML)** — это синтаксический сахар для `React.createElement()`.

Позволяет писать разметку, похожую на HTML, прямо в JavaScript.

---

## 🔹 Подробный ответ

### 1. Что это такое?

- JSX — расширение синтаксиса JavaScript.
- Выглядит как HTML, но работает как JS.
- После компиляции превращается в вызовы `React.createElement()`.

Пример:
```js
const element = <h1>Привет, мир!</h1>;
```

Компилятор превратит это в:

```js
const element = React.createElement("h1", null, "Привет, мир!");
```

#### 2. Особенности JSX

Можно использовать выражения JS внутри {}

```js
const name = "Ульяна"; 
const element = <h1>Привет, {name}!</h1>;
```



JSX должен иметь один корневой элемент

```js
// Ошибка 
return ( <h1>Заголовок</h1> <p>Текст</p> ); 
// Правильно 
return (
<div>
  <h1>Заголовок</h1>
  <p>Текст</p>
</div>
);

```

Атрибуты пишутся как в JS (camelCase)
```js
<button onClick={handleClick}>Нажми</button>
```

JSX можно использовать в условиях и циклах
```js
{isLoggedIn ? <p>Добро пожаловать</p> : <p>Войдите</p>}
```

### 3. Почему это удобно?

- Позволяет писать **UI декларативно**.
- Код становится понятнее и ближе к привычному HTML.
- Легче видеть структуру компонента.

---

✅ **Итог:**

JSX — это **синтаксис для описания React-элементов**, который выглядит как HTML, но компилируется в JavaScript (`React.createElement`).
