## 🔹 Подробный ответ

1. **Компонентный подход**
    - UI разбит на независимые, переиспользуемые компоненты.
    - Упрощает поддержку и масштабирование.
2. **JSX**
    - Синтаксис, похожий на HTML, но внутри JS.
    - Компилируется в `React.createElement()`.
3. **Virtual DOM**
    - React сравнивает старое и новое состояние DOM и обновляет только изменившиеся элементы.
    - Минимизирует прямые манипуляции с DOM → высокая производительность.
4. **Однонаправленный поток данных (props)**
    - Данные передаются от родителя к дочернему компоненту.
    - Предотвращает неожиданные изменения состояния.
5. **Состояние (state)**
    - Управляет динамическими данными внутри компонента.
    - Любое изменение state вызывает перерендер компонента.
6. **Хуки (Hooks)**
    - Позволяют использовать state и другие возможности React в функциональных компонентах.
    - Примеры: `useState`, `useEffect`, `useRef`.
7. **Повторное использование и композиция**
    - Компоненты можно комбинировать, строя сложные интерфейсы из простых блоков.
8. **Высокая производительность**
    - Благодаря Virtual DOM и оптимизации рендеринга.

✅ **Итог:**

React — это **компонентная библиотека** с **виртуальным DOM, JSX, однонаправленным потоком данных и хуками**, которая облегчает построение динамических и переиспользуемых интерфейсов.
