HTMLCollection - это динамическая коллекция, которая представляет собой массивоподобный итерируемый объект дочерних элементов.

NodeList - статический список нод или узлов, в который входят все найденные в документе элементы

getElementsByClassName - HTMLCollection

querySelectorAll - NodeList

Различие между методами в том, что если в разметку динамически добавить элемент, то обновленные данные будут присутствовать только в HTMLCollection.

## **HTMLCollection**

- **Живая коллекция** (live collection) - автоматически обновляется при изменении DOM
    
- **Только элементы** (тэги) - не включает текстовые узлы, комментарии и т.д.
    
- **Доступ по имени/ID** через именованные свойства
    

javascript

const htmlCollection = document.getElementsByClassName('item');
console.log(htmlCollection.length); // 3

// Добавляем новый элемент
const newElement = document.createElement('div');
newElement.className = 'item';
document.body.appendChild(newElement);

console.log(htmlCollection.length); // 4 - автоматически обновилась!

## **NodeList**

- **Обычно неживая коллекция** (кроме некоторых методов)
    
- **Любые узлы** - элементы, текстовые узлы, комментарии
    
- **Более современные методы** обхода
    

javascript

const nodeList = document.querySelectorAll('.item');
console.log(nodeList.length); // 3

// Добавляем новый элемент
const newElement = document.createElement('div');
newElement.className = 'item';
document.body.appendChild(newElement);

console.log(nodeList.length); // 3 - НЕ обновилась!

## **Примеры методов:**

javascript

// HTMLCollection (live)
const liveCollection = document.getElementsByTagName('div');
const byClass = document.getElementsByClassName('test');
const byName = document.forms; // Коллекция форм

// NodeList (mostly static)
const staticList = document.querySelectorAll('div.className');
const childNodes = document.body.childNodes; // Этот NodeList - ЖИВОЙ!

## **Методы обхода:**

javascript

const nodeList = document.querySelectorAll('.item');

// NodeList поддерживает forEach
nodeList.forEach(element => {
  console.log(element);
});

// HTMLCollection НЕ поддерживает forEach
const htmlCollection = document.getElementsByClassName('item');

// Преобразование в массив
const arrayFromNodeList = Array.from(nodeList);
const arrayFromHTMLCollection = Array.from(htmlCollection);

## **Ключевой вывод:**

- Используйте **HTMLCollection** когда нужны автоматические обновления
    
- Используйте **NodeList** (`querySelectorAll`) когда нужна стабильная коллекция
    
- **NodeList** более универсален и современен
