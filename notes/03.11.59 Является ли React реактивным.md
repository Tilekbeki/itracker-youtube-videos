### 🟢 Что значит «реактивный»?

В реактивных фреймворках (Vue, Svelte, MobX):

- Свойства «оборачиваются» реактивными прокси.
- Любое изменение автоматически «подтягивает» связанный UI.

---

### 🟢 Как работает React

- В React нет «магии» автотрекинга.
- Компонент обновляется только если явно вызвать `setState` (классы) или `setX` (хуки).
- После этого запускается механизм **Fiber** → пересчёт дерева → reconciliation → обновление DOM.
