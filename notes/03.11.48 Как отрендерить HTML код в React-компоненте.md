Чтобы вставить HTML-код в компонент, используется `dangerouslySetInnerHTML`:
### 1. Почему обычный рендер не работает
```js
const html = "<p>Привет</p>";
return <div>{html}</div>;
```

- Результат: текст `<p>Привет</p>` отображается **как строка**, а не как HTML.
- React **экранирует HTML**, чтобы предотвратить XSS-атаки.

---

### 2. Как безопасно вставить HTML

- Используется объект с ключом `__html`:
```js
const html = "<p style='color:red'>Привет, React!</p>";

function App() {
  return <div dangerouslySetInnerHTML={{ __html: html }} />;
}
```

- React вставляет HTML **внутрь элемента**.
- **Важно:** проверять и очищать HTML перед вставкой, если он приходит из внешних источников.

---

### 3. Альтернатива: JSX

- Если HTML заранее известен и безопасен, лучше **писать через JSX**, а не через строку:
```js
<div>
  <p style={{ color: "red" }}>Привет, React!</p>
</div>
```

JSX безопаснее и более читаемый.
