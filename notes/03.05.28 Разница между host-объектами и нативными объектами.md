**host-объекты** - это объекты, которые предоставляются средой выполнения, то есть браузером или nodejs.

- window
- document
- location
- history

**нативные объекты** - объекты, которые являются частью языка JavaScript.

- String
- Object
- RegExp
- Function
- Array
