- **React State** — локальное состояние, живёт только внутри компонента. Используется для данных, которые нужны конкретному компоненту (форма, модальное окно).

Автоматически удаляется при размонтировании компонента.

- **Redux State** — глобальное состояние, живёт в одном **store** и доступно всем компонентам. Используется для данных, которые нужно **разделять между разными частями приложения** (авторизация, корзина, фильтры).

Долго живёт (даже при размонтировании компонента).
