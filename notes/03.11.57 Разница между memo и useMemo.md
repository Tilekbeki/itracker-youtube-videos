- **`React.memo`** — HOC для _компонентов_. Запоминает результат рендера, если пропсы не изменились.
- **`useMemo`** — _хук_, который кеширует результат выполнения функции внутри компонента. (при тяжеловестных вычислениях, при статичных пропсах)

### 📌 Главное различие

- `React.memo` → оптимизирует **целый компонент** (мемоизация JSX-результата).
- `useMemo` → оптимизирует **значения внутри компонента** (мемоизация результата функции).
