**Generics (общие типы)** — это механизм TypeScript, позволяющий писать **обобщённый код**, который работает с разными типами, сохраняя типовую безопасность.

Они задаются через `<T>` и позволяют **передавать тип как параметр**.

Пример:

```tsx
function identity<T>(arg: T): T {
  return arg;
}

identity<string>("hello"); // string
identity<number>(42);      // number

```

---

## 🔹 Подробный ответ

### 1. Зачем нужны generics

Без них пришлось бы использовать `any`, что убирает смысл типизации.

```tsx
function identity(arg: any): any {
  return arg; // теряем информацию о типе
}

```

Generics позволяют сделать функцию **гибкой**, но с сохранением типа.

---

### 2. Синтаксис

```tsx
function identity<T>(arg: T): T {
  return arg;
}

```

- `<T>` — обобщённый параметр типа.
- При вызове можно указать тип явно: `identity<string>("hi")`.
- Или TypeScript выведет его автоматически: `identity(123)` → `number`.

---

### 3. Generics в разных конструкциях

### 🔹 В функциях

```tsx
function getFirst<T>(arr: T[]): T {
  return arr[0];
}

const first = getFirst([1, 2, 3]); // number

```

### 🔹 В интерфейсах

```tsx
interface Box<T> {
  value: T;
}

const stringBox: Box<string> = { value: "hello" };

```

### 🔹 В классах

```tsx
class Repository<T> {
  private items: T[] = [];
  add(item: T) {
    this.items.push(item);
  }
  getAll(): T[] {
    return this.items;
  }
}

const userRepo = new Repository<string>();
userRepo.add("Ulyana");

```

---

### 4. Ограничения (extends)

Можно ограничивать обобщённый тип.

```tsx
function logLength<T extends { length: number }>(arg: T): void {
  console.log(arg.length);
}

logLength("Hello"); // ✅
logLength([1, 2, 3]); // ✅
logLength(42); // ❌ number не имеет length

```

---

### 5. Плюсы

- Универсальность (один код — разные типы).
- Безопасность (нет `any`).
- Автодополнение и строгая проверка типов в IDE.

---

✅ **Итог:**

**Generics** в TypeScript позволяют писать **универсальный и безопасный код**, который работает с разными типами, сохраняя информацию о типах.
