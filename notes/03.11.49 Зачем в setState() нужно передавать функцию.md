Функцию в `setState` используют, когда новое состояние зависит от предыдущего.

Так гарантируется, что мы получаем **актуальное состояние**, даже если вызовы `setState` асинхронны.

---

## 🔹 Подробный ответ

### 1. Асинхронность setState

- `setState` **не обновляет state мгновенно**, React может **батчить несколько вызовов** для оптимизации.
- Если передать объект напрямую:
```js
this.setState({ count: this.state.count + 1 });
this.setState({ count: this.state.count + 1 });
```
- `this.state.count` может быть одинаковым в обоих вызовах → **ошибка в результате**.

---

### 2. Использование функции

- Функция получает `prevState` и `props`:
```js
this.setState((prevState, props) => ({
  count: prevState.count + 1
}));
```

- Даже если вызовы батчатся, `prevState` всегда актуален → **результат правильный**.

---

### 3. В функциональных компонентах (`useState`)

- Аналогичная логика:
```js
const [count, setCount] = useState(0);

// Функция для корректного обновления
setCount(prev => prev + 1);
```
Гарантирует правильное обновление при множественных вызовах.
