**SyntheticEvent** — это обёртка над нативным событием браузера в React.

Она работает одинаково во всех браузерах и предоставляет единый интерфейс для работы с событиями.

---

## 🔹 Подробный ответ

### 🟢 Что это?

- В React все события обрабатываются через **систему синтетических событий** (`SyntheticEvent`).
- Это кроссбраузерная обёртка над нативными событиями (`MouseEvent`, `KeyboardEvent` и др.).
- Позволяет React контролировать события и использовать **одну систему очередей** для всех компонентов.

Пример:

```js
function Button() {
  const handleClick = (e) => {
    console.log(e);             // SyntheticEvent
    console.log(e.nativeEvent); // исходное событие браузера
  };

  return <button onClick={handleClick}>Click</button>;
}


```

### 🟢 Особенности

1. **Кроссбраузерность** — React сглаживает различия между браузерами.
2. **Пуллинг событий** — `SyntheticEvent` переиспользуется для оптимизации памяти:
    - После вызова обработчика свойства события (`e.target`, `e.type`) могут быть очищены.
    - Чтобы сохранить данные, нужно вызвать `e.persist()`.

```js
function Input() {
  const handleChange = (e) => {
    e.persist();
    setTimeout(() => console.log(e.target.value), 1000);
  };
  return <input onChange={handleChange} />;
}
```

3. Поддерживает все типы: мышь, клавиатура, форма, фокус, тач, колёсико, и т. д.

---

### 🟢 Зачем нужны SyntheticEvent?

- Унификация работы с событиями.
- Более лёгкий контроль React над системой событий (используется делегирование через `document`).
- Производительность (меньше обработчиков напрямую на DOM).
