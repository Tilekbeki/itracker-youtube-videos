**React.StrictMode** — это компонент-обёртка, который помогает **находить потенциальные проблемы в приложении** в разработке.

Преимущества:

1. Ловит небезопасные методы жизненного цикла.
2. Предупреждает о побочных эффектах.
3. Проверяет устаревшие API.
4. Дублирует рендер компонента для выявления проблем с чистотой кода.

### 1. Что такое StrictMode

- Компонент `<React.StrictMode>` **не рендерится в DOM**.
- Работает **только в режиме разработки** (dev), не влияет на production.
- Аналог `"use strict"` в JS, но для React-кода и компонентов.

Пример использования:
```js
import React from "react";
import ReactDOM from "react-dom/client";
import App from "./App";

const root = ReactDOM.createRoot(document.getElementById("root"));
root.render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
);
```

### 2. Основные проверки StrictMode

1. **Дублированный вызов рендера компонентов**
    - Помогает выявить побочные эффекты в `useEffect` и конструкторе.
2. **Проверка устаревших методов жизненного цикла**
    - Например, `componentWillMount`, `componentWillReceiveProps` → предупреждения в консоли.
3. **Проверка небезопасных ссылок и ключей**
    - Например, `findDOMNode` или повторяющиеся ключи в списках.
4. **Предупреждает о побочных эффектах**
    - Например, если `useEffect` изменяет state без очистки → предупреждение.

---

### 3. Преимущества использования

- Улучшает **качество кода** и стабильность приложения.
- Помогает **раньше находить баги**, особенно в новых версиях React.
- Позволяет **готовиться к будущим релизам React** (например, Concurrent Mode).
