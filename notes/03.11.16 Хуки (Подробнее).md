Хуки (Hooks) — это функции, которые позволяют "подключать" в функциональные компоненты такие возможности React, как **состояние, жизненный цикл, контекст, оптимизация производительности** и т.д.

👉 Добавлены в React 16.8.

---

## 🔹 Виды хуков

### 1. **Базовые хуки**

- **`useState`** — хранение локального состояния.
```js
const [count, setCount] = useState(0);
```
- useEffect — побочные эффекты (API-запросы, подписки, работа с DOM).
```js
useEffect(() => {
  console.log("Count изменился:", count);
  return () => console.log("Cleanup"); // выполняется при размонтировании
}, [count]);
```
- useContext— доступ к значению контекста.
```js
const theme = useContext(ThemeContext);
```

### 2. **Хуки для оптимизации**

- **`useMemo`** — мемоизация вычислений.
```js
const expensiveValue = useMemo(() => heavyCalc(num), [num]);
```
- useCallback— мемоизация функций (полезно при передаче в дочерние компоненты).
```js
const handleClick = useCallback(() => setCount(c => c + 1), []);
```
- useRef— доступ к DOM-элементам или хранение значения, которое не вызывает ререндер.
```js
const inputRef = useRef(null);
```

### 3. **Хуки для сложных сценариев**

- **`useReducer`** — альтернатива `useState` для сложного состояния (похоже на Redux).
```js
const [state, dispatch] = useReducer(reducer, initialState);
```

- **`useLayoutEffect`** — работает как `useEffect`, но выполняется **синхронно** после рендера (для измерений DOM).
- **`useImperativeHandle`** — управление значением `ref` при использовании `forwardRef`.
- **`useDebugValue`** — помогает дебажить кастомные хуки.
### 4. **Кастомные хуки**

Ты можешь создавать свои хуки, чтобы переиспользовать бизнес-логику:
```js
function useWindowWidth() {
  const [width, setWidth] = useState(window.innerWidth);
  useEffect(() => {
    const onResize = () => setWidth(window.innerWidth);
    window.addEventListener("resize", onResize);
    return () => window.removeEventListener("resize", onResize);
  }, []);
  return width;
}

function App() {
  const width = useWindowWidth();
  return <div>Ширина: {width}</div>;
}
```

## 🔹 Правила хуков

1. Хуки можно вызывать **только на верхнем уровне** (не внутри условий, циклов, вложенных функций).
2. Хуки можно использовать **только в функциональных компонентах** или **кастомных хуках**.
3. Всегда начинай имя кастомного хука с `use...`.
## 🔹 Плюсы хуков

✅ Упрощают код (без классов).

✅ Удобное разделение логики (кастомные хуки).

✅ Лёгкая композиция.

✅ Декларативный стиль.

## 🔹 Минусы хуков

❌ Нужно помнить правила хуков.

❌ Возможны лишние ререндеры, если неправильно использовать `useEffect`.

❌ Иногда сложнее дебажить, чем классовые компоненты.
