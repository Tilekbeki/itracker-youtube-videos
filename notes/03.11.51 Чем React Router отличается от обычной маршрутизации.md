### 1. Обычная (серверная) маршрутизация

- Пользователь кликает по ссылке → браузер отправляет запрос на сервер.
- Сервер возвращает **новую HTML-страницу**.
- Каждое действие = полная перезагрузка страницы.

Плюсы:

✔️ Просто, нативно.

✔️ Хорошо работает с SEO.

Минусы:

❌ Медленнее (каждый раз загрузка страницы).

❌ Нет плавных переходов.

---

### 2. React Router (клиентская маршрутизация)

- Приложение загружается **один раз** (SPA).
- При переходе по ссылке меняется только **часть UI**.
- React Router использует **HTML5 History API (`pushState`, `replaceState`)**, чтобы изменять URL **без перезагрузки страницы**.

Плюсы:

✔️ Быстрые переходы.

✔️ Плавный UX, без перезагрузки.

✔️ Можно динамически рендерить компоненты.

Минусы:

❌ Нужно отдельно настраивать SEO (т.к. по умолчанию один HTML).

❌ Нужно настраивать сервер, чтобы все пути вели на `index.html`.
