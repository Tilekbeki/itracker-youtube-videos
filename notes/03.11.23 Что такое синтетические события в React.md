**Синтетические события в React — это обёртка над нативными DOM-событиями.**

**Они работают одинаково во всех браузерах и соответствуют спецификации W3C.**

// Синтетические события — это унифицированный слой над нативными событиями для кроссбраузерности и оптимизации, плюс с поддержкой делегирования.

- React не использует нативные события напрямую. Вместо этого он создаёт **SyntheticEvent** — кроссбраузерную оболочку, которая:
    1. Нормализует поведение событий (например, `onChange`, `onClick`) между разными браузерами.
    2. Имеет такое же API, как нативные события (например, `event.target`, `event.preventDefault()`).
    3. Использует механизм **event delegation** (делегирование событий): обработчики вешаются на корневой элемент (обычно `document`), а не на каждый узел. Это ускоряет работу.
- **Особенности:**
    1. События в React работают одинаково во всех браузерах.
    2. SyntheticEvent **"пулается"** (event pooling) для оптимизации: после вызова обработчика его свойства могут быть очищены. Чтобы использовать событие асинхронно — нужно вызвать `event.persist()`.
    3. Работают поверх нативных событий, но React управляет ими сам.
