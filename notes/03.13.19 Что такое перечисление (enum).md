**Enum (перечисление)** — это способ создать именованный набор констант, чтобы использовать их вместо "магических значений".

- Можно создавать **числовые**, **строковые** и **гетерогенные** enum.

Пример:

```tsx
enum Direction {
  Up,
  Down,
  Left,
  Right
}

let move: Direction = Direction.Up;

```

---

## 🔹 Подробный ответ

### 1. Числовые enum

- По умолчанию значения **начинаются с 0** и увеличиваются на 1.

```tsx
enum Direction {
  Up,    // 0
  Down,  // 1
  Left,  // 2
  Right  // 3
}

console.log(Direction.Up); // 0
console.log(Direction[2]); // "Left"

```

- Можно задавать свои числа:

```tsx
enum Direction {
  Up = 1,
  Down,
  Left,
  Right
}
// Up=1, Down=2, Left=3, Right=4

```

---

### 2. Строковые enum

- Каждый элемент — строка, **нет обратного маппинга**.

```tsx
enum Direction {
  Up = "UP",
  Down = "DOWN",
  Left = "LEFT",
  Right = "RIGHT"
}
console.log(Direction.Up); // "UP"

```

---

### 3. Гетерогенные enum

- Смешиваются строки и числа (редко используют).

```tsx
enum BooleanLike {
  No = 0,
  Yes = "YES"
}

```

---

### 4. Особенности

- **Обратное отображение** работает только для числовых enum.
- Используются для **повышения читаемости кода**, предотвращения "магических чисел/строк".
- Могут быть **const enum** → компилируются в литералы для оптимизации.

```tsx
const enum Direction {
  Up,
  Down
}
let move = Direction.Up; // компилируется в: let move = 0;

```

---

✅ **Итог:**

**Enum** в TypeScript — это именованные константы (числовые или строковые), которые повышают читаемость кода и предотвращают ошибки от использования "магических значений".
