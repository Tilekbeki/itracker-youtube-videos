**JSX** в TypeScript — это синтаксис, расширяющий JavaScript (похожий на HTML), который используется в React.

TypeScript поддерживает **3 режима JSX**:

1. **preserve** → оставляет JSX как есть (требует дальнейшей обработки, например Babel).
2. **react** → компилирует в `React.createElement(...)`.
3. **react-native** → оставляет JSX (как `preserve`), но используется для React Native.

---

## 🔹 Подробный ответ

### 1. Что такое JSX?

- JSX (JavaScript XML) — синтаксический сахар для вызова функций.

TypeScript понимает JSX и проверяет типы компонентов.

---

### 2. Режимы JSX в TypeScript

Включаются через `tsconfig.json` → `"jsx": "preserve" | "react" | "react-native"`.

- **preserve**
    - JSX остаётся нетронутым в выходном коде.
    - Нужна дополнительная трансформация (например Babel или SWC).
    - Подходит, если сборка настроена на дальнейшую обработку.
- **react**
    - Прямо компилируется в `React.createElement`.
    - Подходит для старых проектов без дополнительного шага сборки.
- **react-native**
    - JSX сохраняется (как в `preserve`).
    - Используется в React Native (где компиляция идёт по-своему).

⚡️ В новых версиях (React 17+) добавили `"jsx": "react-jsx"`, где вместо `React.createElement` используется новый JSX-трансформ.

---

### 3. Типизация JSX

TypeScript проверяет:

- **тип пропсов** у компонентов,
- **валидность HTML-атрибутов**,
- **children**.

---

✅ **Итог:** JSX в TS — это синтаксис для React, а режимы управляют тем, как компилятор обрабатывает JSX (оставить как есть, преобразовать в `createElement`, или передать дальше для React Native).
