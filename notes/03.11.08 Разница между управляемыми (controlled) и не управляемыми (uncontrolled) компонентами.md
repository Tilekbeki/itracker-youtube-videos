- **Управляемые (Controlled)** → значение элемента формы хранится в **state React** и обновляется через `onChange`.
- **Неуправляемые (Uncontrolled)** → значение хранится в **DOM** и читается через `ref`.
## 🔹 Подробный ответ

### 1. Управляемые компоненты (Controlled Components)

- Источник правды → **state React**.
- Каждый ввод обновляет state, который рендерит новое значение в поле.
```js
function ControlledInput() {
  const [value, setValue] = React.useState("");

  return (
    <inputvalue={value}
      onChange={e => setValue(e.target.value)}
    />
  );
}
```
✅ Полный контроль со стороны React.

⚠ Но при большом количестве полей может быть "шумный" код.

---

### 2. Неуправляемые компоненты (Uncontrolled Components)

- Источник правды → **сам DOM**.
- Используем `ref`, чтобы получить значение, когда нужно.

```js
function UncontrolledInput() {
  const inputRef = React.useRef(null);

  function handleSubmit() {
    alert(inputRef.current.value);
  }

  return (
    <><input ref={inputRef} />
      <button onClick={handleSubmit}>Отправить</button>
    </>
  );
}
```
✅ Код проще, меньше ререндеров.

⚠ Меньше контроля → сложнее валидировать и синхронизировать данные.

---

### 3. Сравнение

|Подход|Источник данных|Когда использовать?|
|---|---|---|
|Controlled|State в React|Когда нужен полный контроль (валидация, динамика, реактивность).|
|Uncontrolled|DOM (ref)|Когда нужно быстро и просто (например, форма с 1–2 полями).|

---

✅ **Итог:**

- Controlled → управляется React, больше контроля, но больше кода.
- Uncontrolled → управляется DOM, проще, но меньше гибкости.
