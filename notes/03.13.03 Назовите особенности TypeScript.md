Особенности TypeScript:

1. Статическая типизация.
2. Поддержка современных возможностей JS.
3. Совместимость с JavaScript (любой JS-код — валидный TS-код).
4. Улучшенные возможности ООП (модификаторы доступа, интерфейсы, абстрактные классы).
5. Поддержка конфигурации через `tsconfig.json`.
6. Богатая IDE-поддержка (автокомплит, навигация, рефакторинг).

---

## 🔹 Подробный ответ

### 1. Статическая типизация

- Проверка типов на этапе компиляции → меньше багов в рантайме.
```js
let age: number = 25;
age = "25"; // ❌ Ошибка при компиляции
```
### 2. Совместимость с JS

- Любой `.js` можно переименовать в `.ts` и он будет работать.
- Постепенное внедрение в проект.

---

### 3. Поддержка ООП-фич

- Модификаторы доступа (`public`, `private`, `protected`).
- `readonly` свойства.
- `abstract` классы и методы.
- Интерфейсы и дженерики.

---

### 4. Улучшенные инструменты разработки

- Автодополнение (IntelliSense).
- Навигация по коду и безопасный рефакторинг.
- Подсветка ошибок до запуска кода.

---

### 5. Гибкая конфигурация

- `tsconfig.json` позволяет настроить таргет (ES5, ES6, ESNext), систему модулей (CommonJS, ESModules), strict-режимы и директории сборки.

---

### 6. Поддержка сторонних библиотек

- Через **type definitions** (`@types/*`).
    
    Например:
    ```bash
    npm install @types/lodash
    ```
### 7. Повышенная надёжность и масштабируемость

- Отлично подходит для больших проектов и командной разработки.
- Легче сопровождать код → меньше багов.
