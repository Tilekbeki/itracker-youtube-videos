- **Mounting (монтирование):** `constructor`, `render`, `componentDidMount`.
- **Updating (обновление):** `shouldComponentUpdate`, `render`, `componentDidUpdate`.
- **Unmounting (размонтирование):** `componentWillUnmount`.
- **Error Handling (ошибки):** `componentDidCatch`, `static getDerivedStateFromError`.

В функциональных компонентах всё это реализуется через **`useEffect` и `useLayoutEffect`**.

### 1. Mounting (Монтирование)

Когда компонент впервые появляется в DOM:

- `constructor` → инициализация state, привязка методов.
- `static getDerivedStateFromProps(props, state)` → синхронизация state с props.
- `render()` → возвращает JSX.
- `componentDidMount()` → вызывается один раз, удобно для запросов к API.

---

### 2. Updating (Обновление)

Когда изменяются `props` или `state`:

- `static getDerivedStateFromProps()` → редко используется.
- `shouldComponentUpdate(nextProps, nextState)` → позволяет оптимизировать рендер (аналог `PureComponent`).
- `render()` → снова вызывается для обновления UI.
- `getSnapshotBeforeUpdate(prevProps, prevState)` → позволяет получить данные из DOM перед обновлением.
- `componentDidUpdate(prevProps, prevState)` → вызывается после обновления, удобно для запросов.

---

### 3. Unmounting (Размонтирование)

Когда компонент удаляется из DOM:

- `componentWillUnmount()` → отписки, очистка таймеров, отмена запросов.

---

### 4. Error Handling (Обработка ошибок)

Для ошибок рендера или методов жизненного цикла:

- `static getDerivedStateFromError(error)` → обновляет state при ошибке.
- `componentDidCatch(error, info)` → логирование ошибок.

---

### 5. В функциональных компонентах

Все эти стадии покрываются хуками:

- `useEffect(() => {}, [])` → `componentDidMount` + `componentWillUnmount`.
- `useEffect(() => {}, [deps])` → `componentDidUpdate`.
- `useLayoutEffect` → аналог `getSnapshotBeforeUpdate`.
- Ошибки → обрабатываются через Error Boundaries (обычно классовые компоненты).
