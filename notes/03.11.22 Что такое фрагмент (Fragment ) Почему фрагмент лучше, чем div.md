**Фрагмент (Fragment)**

— это специальный компонент React ( <React.Fragment>или <>...</>), который позволяет группировать несколько элементов без создания лишнего DOM-узла.

Фрагмент лучше, чем <div>

, потому что:

- 🚀 **Нет лишних DOM-узлов** → меньше нагрузка на браузер.
- 🎨 **Чистая верстка** → не мешает стилям (например, при использовании `flex` или `grid`).
- ⚡ **Оптимизация производительности** → меньше памяти и вычислений.
- 🧩 **Лучше для семантики** → структура HTML остаётся правильной (нет случайных `div`).
