Да, **TypeScript поддерживает перегрузку функций** — через объявление нескольких сигнатур функции с разными типами параметров. Реализация при этом одна.

---

## 🔹 Подробный ответ

В **TypeScript** перегрузка функций работает так:

1. Определяются несколько сигнатур (объявлений) функции.
2. Затем пишется одна реализация, которая должна покрывать все случаи.

Пример:
```ts
function getValue(x: string): string;
function getValue(x: number): number;
function getValue(x: string | number): string | number {
  if (typeof x === "string") {
    return `Строка: ${x}`;
  }
  return x * 2;
}

console.log(getValue("TS")); // "Строка: TS"
console.log(getValue(10));   // 20
```

🔹 Здесь определены две перегрузки (`string` и `number`), но реализация одна.

---

## ⚠️ Особенности перегрузки в TS:

- Работает только на **уровне типов** (во время компиляции).
- В рантайме (в JS) остаётся только одна функция.
- Нужно вручную обрабатывать разные типы аргументов.
- Нельзя написать две реализации — только одну.

---

✅ **Итог:**

TypeScript поддерживает **перегрузку сигнатур функций**, но это **синтаксический сахар для типизации**, а не настоящая перегрузка как в Java/C#.
