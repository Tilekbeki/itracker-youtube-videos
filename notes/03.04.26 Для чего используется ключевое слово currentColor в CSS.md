Ключевое слово currentColor можно использовать в качестве значения для CSS-свойства, принимающего цвет. Например, color, background-color, box-shadow. Браузер подставит вместо currentColor текущее значение свойства [color](https://doka.guide/css/color/). Что позволяет при изменении основной палитры автоматически изменить зависящие через currentColor цвета, например цвет тени или фона.
