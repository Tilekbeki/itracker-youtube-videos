- **`void`** → функция ничего не возвращает.
- **`never`** → функция _никогда_ не завершится нормально (ошибка или бесконечный цикл).
- **`unknown`** → значение неизвестного типа, требует проверки перед использованием.

---

## 🔹 Подробный ответ

### 1. `void`

- Используется для функций **без возвращаемого значения**.
- В JS возвращает `undefined`.

```tsx
function logMessage(msg: string): void {
  console.log(msg);
}

```

---

### 2. `never`

- Тип, который **никогда не наступает**.
- Функция либо бросает ошибку, либо выполняется бесконечно.
- Полезен для **исчерпывающих проверок (exhaustive checks)**.

```tsx
function throwError(message: string): never {
  throw new Error(message);
}

function infiniteLoop(): never {
  while (true) {}
}

```

---

### 3. `unknown`

- Безопасная альтернатива `any`.
- Можно присвоить что угодно, но **нельзя использовать без проверки**.
```ts
let data: unknown = fetchSomething();

if (typeof data === "string") {
  console.log(data.toUpperCase());
}
```

### 🔹 Сравнение

| Тип         | Когда использовать?              | Особенности                           |
| ----------- | -------------------------------- | ------------------------------------- |
| **void**    | Функция ничего не возвращает     | Обычно `undefined`                    |
| **never**   | Функция не завершится нормально  | Ошибки, бесконечные циклы             |
| **unknown** | Данные из неизвестного источника | Требует проверки перед использованием |
