- **Promise.all()** - принимает массив промисов и возвращает новый промис, который будет выполнен только тогда, когда все промисы в массиве будут выполнены. Если хотя бы один промис из массива отклонится, то Promise.all() тоже отклонится.
- **Promise.any()** - принимает массив промисов и возвращает новый промис, который будет выполнен, когда хотя бы один из промисов в массиве будет выполнен успешно. Если все промисы отклонятся, то Promise.any() тоже отклонится.
- **Promise.race() -** принимает массив промисов и возвращает новый промис, который будет выполнен, когда любой из промисов в массиве будет выполнен, независимо от того, успешно или нет. Результат выполнения первого завершившегося промиса будет использован для выполнения Promise.race().
