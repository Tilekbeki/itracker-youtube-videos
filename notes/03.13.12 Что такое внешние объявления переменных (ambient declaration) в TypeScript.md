## 🔹 Краткий ответ (для собеса):

**Внешние объявления (ambient declarations)** — это объявления переменных, функций, классов или модулей, которые существуют **во внешнем коде**, чтобы TypeScript мог их **типизировать**, не создавая реального кода.

- Используется ключевое слово `declare`.
- Часто применяются для работы с библиотеками JS без типов.

Пример:

```tsx
declare const API_KEY: string;
declare function fetchData(url: string): Promise<any>;

```

> TypeScript понимает их типы, но ничего не компилирует в JS.

---

## 🔹 Подробный ответ

### 1. Что это такое

- TypeScript хочет знать типы всего, что используется.
- Если библиотека написана на JS и у неё нет типов — можно написать **ambient declarations** (`.d.ts`) для корректной типизации.
- Они **не генерируют код** при компиляции.

---

### 2. Примеры

### 🔸 Переменные и функции

```tsx
declare const API_URL: string;
declare function log(message: string): void;

```

### 🔸 Классы

```tsx
declare class MyLib {
  constructor(name: string);
  greet(): void;
}

```

### 🔸 Модули

```tsx
declare module "lodash" {
  export function debounce(func: Function, wait: number): Function;
}

```

---

### 3. Где применяются

- Для **сторонних JS-библиотек**, когда нет типов.
- В **файлах `.d.ts`** для описания API, чтобы IDE могла подсказать типы.
- При работе с глобальными переменными.

---

### 4. Отличие от обычного объявления

- `declare` → **типизация без кода**.
- Обычное объявление (`const`, `function`) → создаёт код в JS.

```tsx
declare const API_KEY: string; // Только тип
const API_KEY = "123";         // Тип + код

```

---

✅ **Итог:**

**Ambient declaration (`declare`)** — это способ сообщить TypeScript о существующих внешних сущностях без генерации кода, чтобы работать с JS-библиотеками безопасно по типам.
