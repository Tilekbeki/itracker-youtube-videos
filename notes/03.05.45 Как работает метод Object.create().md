Метод `Object.create()` используется для создания нового объекта с заданным прототипом.
```js
Object.create(proto, propertiesObject)
```

proto: Объект, который станет прототипом нового объекта. propertiesObject (необязательный): Объект, определяющий дескрипторы свойств нового объекта.

```js
const animal = {
    type: 'mammal',
    sound: 'makes noise',
    makeSound: function() {
        console.log(this.sound);
    }
};

const dog = Object.create(animal);
dog.sound = 'barks';

dog.makeSound(); // Output: barks
```
