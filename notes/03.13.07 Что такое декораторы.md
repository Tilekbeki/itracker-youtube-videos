**Декораторы** — это специальные функции в TypeScript, которые позволяют изменять поведение классов, методов, свойств или параметров.

Они работают как "аннотации" или "метаданные".

---

## 🔹 Подробный ответ

### 1. Определение

Декоратор — это функция, которая принимает в качестве аргумента цель (например, класс или метод) и может её модифицировать или дополнять.

Используются с `@` перед определением.

Пример:
```ts
function Log(target: any, propertyKey: string, descriptor: PropertyDescriptor) {
  console.log(`Вызван метод: ${propertyKey}`);
}

class User {
  @Log
  getData() {
    return "User data";
  }
}
```

Здесь `@Log` выполняется при объявлении метода.

---

### 2. Виды декораторов

1. **Класса** → применяются к классу.

```ts
function Controller(constructor: Function) {
  console.log(`Класс: ${constructor.name}`);
}

@Controller
class User {}
```

2. **Метода** → модифицируют метод (часто для логирования).
3. **Свойства** → можно добавлять метаданные к свойству.
4. **Параметра метода** → работают с аргументами функций.

---

### 3. Применение

- Логирование.
- Валидация.
- DI (dependency injection) — особенно в Angular.
- Создание метаданных для фреймворков.

---

### 4. Ограничения

- В **чистом JS** пока нет (есть предложение в TC39).
- В **TypeScript** — нужно включить `experimentalDecorators` в `tsconfig.json`.

---

✅ **Итог:** Декораторы — это **функции-метки**, которые позволяют декларативно добавлять новое поведение к классам и их элементам. Особенно часто применяются в Angular и NestJS.
